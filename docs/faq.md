### Warum werde ich nach 20 Minuten automatisch abgemeldet?
Zum Schutz sensibler Personendaten erfolgt nach 20 Minuten Inaktivität eine automatische Abmeldung.

### Wieso ist beim Login ein zusätzlicher Code erforderlich?
Der zweite Faktor erhöht die Sicherheit beim Zugriff.

### Warum sehe ich als User-Administrator eine leere Startseite?
Die Rolle dient primär der **Benutzerverwaltung** und nicht der Formularbearbeitung.

### Was tun, wenn der Browser endlos laedt?
Die Seite aktualisieren (z. B. Taste `F5`).

### Wohin wird der Login-Code gesendet?
An die im **Profil** hinterlegte persönliche E-Mail-Adresse.

### Warum dauert die Zustellung des Codes manchmal länger?
Das Portal versendet den Code sofort; die Zustelldauer haengt vom E-Mail-Anbieter ab.

### Mein Browser füllt das Passwort falsch aus - was tun?
Löschen Sie falsch gespeicherte Zugangsdaten in den **Browser-Einstellungen**.
