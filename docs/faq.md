### Warum werde ich nach 20 Minuten automatisch abgemeldet?
Zum Schutz sensibler Personendaten erfolgt nach 20 Minuten Inaktivitaet eine automatische Abmeldung.

### Wieso ist beim Login ein zusaetzlicher Code erforderlich?
Der zweite Faktor erhoeht die Sicherheit beim Zugriff.

### Warum sehe ich als User-Administrator eine leere Startseite?
Die Rolle dient primaer der **Benutzerverwaltung** und nicht der Formularbearbeitung.

### Was tun, wenn der Browser endlos laedt?
Die Seite aktualisieren (z. B. Taste `F5`).

### Wohin wird der Login-Code gesendet?
An die im **Profil** hinterlegte persoenliche Geschaefts-E-Mail-Adresse.

### Warum dauert die Zustellung des Codes manchmal laenger?
Das Portal versendet den Code sofort; die Zustelldauer haengt vom E-Mail-Anbieter ab.

### Mein Browser fuellt das Passwort falsch aus - was tun?
Loeschen Sie falsch gespeicherte Zugangsdaten in den **Browser-Einstellungen**.
